# HELiX macOS Double-Click App — 1.8.2

![HELiX Screenshot](logo.png)

![HELiX Screenshot](demo.gif)

1. Move `HELiX.app` to Applications if desired.
2. Double-click `HELiX.app`.
3. If macOS blocks it because this development build is not notarized, open **System Settings → Privacy & Security**, scroll to **Security**, and choose **Open Anyway** for HELiX. Then open it again.
